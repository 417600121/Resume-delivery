# 求职投递管理

基于 Vue 3 + Vite 的本地求职投递管理网页，支持投递状态时间线、面试倒计时、Markdown 招聘信息、个人信息分组和 JSON 导入导出。

## 本地运行

```bash
npm install
npm run dev
```

也可以直接双击上级目录的 `打开投递管理.cmd`。

## GitHub Pages

仓库已配置 GitHub Actions。将 `main` 分支推送到 GitHub 后，Actions 会自动构建并部署 `dist`。

首次使用时，在仓库的 **Settings → Pages** 中将部署来源选择为 **GitHub Actions**。

页面地址通常为：

`https://417600121.github.io/Resume-delivery/`
