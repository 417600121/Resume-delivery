## Why

上一轮视觉刷新改善了颜色和间距的一致性，但整体仍然偏向“多个白色卡片叠在一起”的旧式后台风格：圆角、阴影和边框同时出现，页面信息密度与层级关系不够自然，侧栏和顶部操作也没有形成现代桌面工作台应有的安静秩序。用户在记录页需要先辨认装饰性表面，再寻找真正重要的状态、下一步和操作，这与当前主流产品型 Web UI 的内容优先审美不一致。

本次提案将参考 Linear 近期强调的克制、统一、内容优先的工作台界面，结合 Atlassian 设计系统对令牌、间距、字体、边界和无障碍的体系化做法，以及 Apple Human Interface Guidelines 对层级、和谐和一致性的要求，重新确定求职投递工具的桌面端视觉方向。目标不是复制任何品牌，而是建立更轻、更稳、更适合长期使用的现代产品界面。

## What Changes

- 重新定义桌面端视觉基线：以中性灰白画布、石墨文字和单一品牌强调色为主，减少暖色、深色和多种状态色同时争夺注意力。
- 将当前大量卡片化表面改为“页面画布 + 工作面 + 少量浮层”的层级结构，减少不必要的圆角和阴影，只有弹窗、菜单和提示保留明确的浮层深度。
- 重做应用外壳和导航：让侧栏更安静、内容区更突出，统一页面标题、视图控制和主要操作的位置，并为当前视图提供清晰但不过度装饰的选中反馈。
- 重做投递记录工作台：将统计信息压缩为轻量指标带，重新组织搜索、筛选、排序、视图操作、表头、行高、状态标签和操作列，提升长时间扫描和跟进决策效率。
- 重做弹窗、下拉菜单、工具提示和 Markdown 预览，使其拥有统一的标题区、内容区、操作区、边界、动效和焦点状态，避免出现嵌套卡片和厚重阴影。
- 重做个人信息工作区：使用更清晰的分组节奏、列表行和操作层级表达内容，不让空状态或编辑状态产生大面积无意义留白。
- 增加完整的视觉令牌和状态规则，包括排版比例、8px 间距尺度、边框、层级、悬停、按下、选中、禁用、危险、拖拽和 `focus-visible` 状态。
- 保持现有记录、状态时间线、Markdown、导入导出、本地存储和事件语义不变；本次仍然只针对桌面端，不新增移动端适配。

## Capabilities

### New Capabilities

- `modern-job-tracker-ui`: 规定求职投递管理台面向桌面工作场景的现代视觉系统、页面布局、工作台密度和交互状态表现。

### Modified Capabilities

本项目当前没有已同步到 `openspec/specs/` 的主规范文件，因此本次以新的视觉能力规范记录要求；不修改业务数据能力。

## Impact

- 主要影响 `src/styles.css`、`src/App.vue` 以及 `src/components/` 下的表格、个人信息面板和弹窗组件的模板类名与视觉状态。
- 继续使用 Vue 3、Vite 和现有 `lucide-vue-next`，不新增运行时依赖、字体服务或设计系统包。
- 不改变本地存储结构、导入导出格式、状态时间线数据或现有事件接口。
- 需要补充桌面宽屏、受限桌面窗口、空数据、单条/多条记录、弹窗和个人信息分组的视觉验收，并记录与当前版本相比的剩余限制。
